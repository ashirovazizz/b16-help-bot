# b16-help-bot

Telegram-бот DH-центра ИТМО. Сотрудник пишет боту заявку, бот кладёт её карточкой в тему рабочего чата. Там её берёт в работу ответственный, а ответы ходят между чатом и сотрудником через бота.

Первый раздел — персональные страницы на dh.itmo.ru: создать новую или изменить существующую.

## Как это работает

**Сотруднику.** Написать боту `/start` и выбрать:

- **✏️ Изменить мою страницу** — описать, что поменять (можно несколькими сообщениями, фото — файлом) → «📨 Отправить заявку»;
- **🆕 Создать страницу на сайте** — если страницы ещё нет. Бот задаст семь вопросов: имя, подпись, о себе, проекты, курсы, контакты, фото. Необязательные можно пропустить. В конце бот покажет итог: отправить или заполнить заново.

Пока заявка не отправлена, под каждым новым сообщением бот показывает «📝 В заявке сообщений: N. Она ещё не отправлена» с кнопкой «📨 Отправить заявку». Если человек что-то написал и не отправил, через 30 минут бот один раз напомнит (срок меняется в `.env`).

Ответ редактора придёт в этот же чат. Чтобы ответить, достаточно просто написать боту.

**Редактору.** В теме приходит карточка заявки. Под ней — сообщения сотрудника, а для новой страницы — анкета одним сообщением с подписанными полями (удобно копировать в Tilda) и фото. Кнопки:

- ✋ **Беру** — заявка закрепляется за вами, сотрудник видит, кто ведёт;
- ✅ **Готово** — сотрудник получает уведомление;
- ⛔ **Отклонить** — причину напишите ответом на карточку;
- ↩️ **Вернуть в работу** — если сотрудник нашёл ошибку.

Ответ на любое сообщение заявки в теме бот перешлёт сотруднику. Ответ сотрудника придёт в ту же ветку.

По будням в 10:00 бот присылает в тему сводку: что никто не взял и что висит в работе дольше 3 рабочих дней.

Писать боту может любой, кто его найдёт: проверки по чатам нет. В карточке видно, кто прислал заявку.

## Рассылки

Бот помнит всех, кто хоть раз писал ему в личку, и всех, кто уже отправлял заявки. Только им он может написать сам: Telegram не даёт боту писать первым. Запускать рассылки может любой участник рабочего чата. Команды проще выбирать из меню «/» в чате, Telegram сам допишет имя бота.

- `/broadcast текст` — разослать текст. Можно ответить этой командой на сообщение в чате, тогда бот разошлёт его копию, хоть с фото.
- `/pagecheck` — спросить всех: «Всё на вашей странице актуально?» Под вопросом кнопки «✅ Всё актуально», «✏️ Нужно изменить» и «🆕 Страницы нет». Две последние сразу открывают обычную заявку. Не ответившим бот один раз напомнит и потом пришлёт итоги в тот же чат. Сроки по умолчанию: напоминание через 3 дня, итоги через 7. Свои сроки: `/pagecheck 2 5`, без напоминания: `/pagecheck 0 5`.
- `/checkstatus` — итоги последней проверки: кто ответил и как, кто молчит.

Перед отправкой бот показывает, что и скольким людям уйдёт. Отправить или отменить может только тот, кто запустил рассылку. После отправки бот пишет в чат отчёт и отдельно называет тех, кто заблокировал бота.

## Установка на сервер

Нужен любой сервер на Ubuntu или Debian с интернетом. Домен, HTTPS и открытые порты не нужны: бот сам забирает сообщения из Telegram.

1. Зайдите на сервер по SSH и выполните:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/ashirovazizz/b16-help-bot/refs/heads/claude/optimize-personnel-updates-eu31gv/deploy/install.sh | sudo bash
   ```

   Установщик поставит Docker, скачает бота, спросит токен от @BotFather и запустит бота. В конце он напишет команду вида `/setup@имя_бота код`.

   Если `raw.githubusercontent.com` не открывается:

   ```bash
   git clone -b claude/optimize-personnel-updates-eu31gv https://github.com/ashirovazizz/b16-help-bot.git /opt/b16-help-bot
   sudo bash /opt/b16-help-bot/deploy/install.sh
   ```

2. Добавьте бота в рабочий чат. В теме, куда должны приходить заявки, отправьте команду из установщика.
3. Напишите боту в личку `/start` и отправьте тестовую заявку.

Управление на сервере:

| Что | Команда |
|---|---|
| журнал | `cd /opt/b16-help-bot && sudo docker compose logs -f` |
| перезапуск | `cd /opt/b16-help-bot && sudo docker compose restart` |
| обновление | ещё раз команда установки (настройки сохранятся) |
| настройки | `sudo nano /opt/b16-help-bot/.env`, затем перезапуск |

Токен хранится только в `/opt/b16-help-bot/.env` на сервере. Если он где-то засветился, выпустите новый в @BotFather (`/revoke`), впишите его в `.env` и перезапустите бота.

## Настройки (.env)

| Параметр | По умолчанию | Что это |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather |
| `SETUP_CODE` | придумает установщик | код для `/setup` в рабочем чате |
| `DIGEST_TIME` | `10:00` | время утренней сводки, `off` — без сводки |
| `SLA_DAYS` | `3` | через сколько рабочих дней заявка в работе получает ⚠️ |
| `HOLIDAYS` | — | праздники через запятую, в эти дни сводки нет |
| `DRAFT_REMIND_MINUTES` | `30` | через сколько минут напомнить о неотправленной заявке, `0` — не напоминать |
| `CHECK_REMIND_DAYS` | `3` | проверка страниц: через сколько дней напомнить не ответившим, `0` — не напоминать |
| `CHECK_CLOSE_DAYS` | `7` | проверка страниц: через сколько дней прислать итоги |
| `TEAM_PAGE_URL` | `https://dh.itmo.ru/team` | ссылка на страницу команды в вопросе проверки |
| `OPS_CHAT_ID`, `SITE_TOPIC_ID` | — | чат и тема вручную вместо `/setup` (узнать: `/id@имя_бота`) |

## Новый процесс

Процессы описаны в `src/processes.ts`: название, кнопка, значок, подсказка и, если нужно, вопросы анкеты. Добавили запись — в меню бота появилась кнопка. Без вопросов бот принимает свободный текст, с вопросами ведёт по анкете.

Процессы одной группы падают в одну тему. Тему группы задаёт `/setup@имя_бота код группа`; без группы — `site`.
