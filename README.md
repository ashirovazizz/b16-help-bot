# b16-help-bot

Бот DH-центра ИТМО для заявок на персональные страницы сайта [dh.itmo.ru](https://dh.itmo.ru/about): создать страницу, обновить, снять. Первый процесс «бота-помощника» центра. Устроен так, чтобы следующие процессы — мероприятия, HR-запросы, обратная связь — добавлялись новыми модулями.

## Как это работает

```
Реестр People ─► бот создаёт заявку и ссылку-приглашение ─► сотрудник подключается
Сотрудник: «Обновить страницу» ─► форма с текущим текстом ─► заявка редактору
Тема «Сайт»: карточка ─► редактор: Беру / Нужны данные / Опубликовано / Отклонить
Сотрудник: «Всё верно» / «Нужна правка» (молчание 2 рабочих дня = согласие)
Итог: Profiles = новая версия страницы, прошлая — в History, фото — в Drive
Каждое утро: сводка в теме «Сайт» — что просрочено и чей ход
```

- **Google Таблица** на аккаунте центра — источник состояния: реестр, страницы, заявки, история, настройки.
- **Telegram** — вход для сотрудников, карточки и кнопки для редактора, напоминания.
- **Веб-форма** — анкета по личной подписанной ссылке: текущий текст страницы, фото в оригинале.
- **Tilda** правит только редактор, вручную. Бот проверяет, открывается ли страница после публикации.

Подробно:

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — решения, статусы, данные, безопасность;
- [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) — запуск на сервере центра;
- [docs/PROCESS.md](docs/PROCESS.md) — регламент для сотрудников, редактора, стажёра (черновик для Tilda Wiki).

## Разработка

Нужен Node.js 22.

```bash
npm ci
npm run verify   # типы, линтер, тесты
npm run build    # сборка в dist/
```

Локальный запуск без Google: `STORAGE=memory` в `.env` (данные живут только в памяти процесса).

```
src/
  core/        время и рабочие дни, подписи ссылок, замок, журнал
  domain/      поля страницы, статусы и переходы, проверка анкеты
  services/    сценарии процесса, сводка, тексты сообщений
  storage/     хранилище: Google Таблица и память
  telegram/    бот: личка, карточки, кнопки
  web/         форма заявки
  photos/      фото: Drive и память
  scripts/     google:auth, setup:workbook
test/          тесты, включая проверки из раздела 15 ТЗ
```
